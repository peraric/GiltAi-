# GiltAi

GiltAi is an independent AI product. It is intentionally separate from GiltPay.

## Current stage
- Premium dark/gold GiltAi chat UI
- Responsive mobile layout
- New chat and local conversation history
- Provider-neutral architecture
- No API keys committed to the repository

## Roadmap
1. Real GiltAi chat backend
2. Streaming responses
3. Authentication and saved conversations
4. File and image inputs
5. Voice
6. Web research
7. Public API
8. Production deployment

## Security
Store model-provider secrets only in server-side environment variables. Never put API keys in browser JavaScript or commit them to Git.
